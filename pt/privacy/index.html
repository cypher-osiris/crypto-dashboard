Política de privacidade

Última atualização: 23 out 2026

A Lumi Trades mantém este site (lumitrades.io) e a API para agentes (api.lumitrades.io). Coletamos o mínimo possível. Esta página explica o que é coletado, por quem e por quê. Não vendemos dados pessoais e não usamos rastreadores de publicidade.

Newsletter

Se você assinar a newsletter diária gratuita, o e-mail que você digitar é enviado à Kit (ConvertKit), o serviço de e-mail que guarda a lista de assinantes e envia os e-mails. O formulário pede apenas o seu endereço de e-mail, e ele é usado apenas para enviar a newsletter diária.

A Kit pede que você confirme a assinatura por e-mail, e toda newsletter traz um link para cancelar: você pode cancelar quando quiser. Como a maioria dos serviços de e-mail, a Kit pode registrar dados de entrega, como se um e-mail foi aberto. A Kit trata esses dados conforme a própria política de privacidade.

Análise de tráfego

O site conta as visitas com o Cloudflare Web Analytics. Ele não usa cookies e não segue você por outros sites. Só vemos números agregados, como visualizações de página, sites de origem, países e tipos de navegador.

Hospedagem

O site é um conjunto de páginas estáticas hospedadas no GitHub Pages. O GitHub pode registrar os endereços IP dos visitantes e detalhes das requisições para operar e proteger o serviço, conforme a declaração de privacidade do GitHub. O site não tem contas, logins nem formulários de comentários.

Conteúdo e links de terceiros

As páginas carregam fontes do Google Fonts e, em algumas páginas, uma biblioteca de gráficos da CDN jsDelivr. Seu navegador busca os preços ao vivo e os dados de mercado diretamente em APIs públicas (Coinbase Exchange, Kraken, CoinGecko e OKX). Como qualquer requisição na web, isso envia seu endereço IP e dados do navegador a esses provedores. Nada do X, YouTube ou TikTok é incorporado: são links comuns.

Alguns links para corretoras e fabricantes de carteiras são links de afiliado ou de indicação: podemos ganhar uma comissão se você se cadastrar, sem custo para você. Os links exibidos dependem da sua região. Para decidir, seu navegador pergunta seu país a um serviço de geolocalização (api.country.is, ou ipapi.co como alternativa) ou usa seu fuso horário. A resposta fica no seu navegador e não é enviada para nós. Ao seguir um link para outro site, vale a política de privacidade desse site.

Guardado no seu navegador

Este site não usa cookies. Seu navegador guarda o idioma escolhido e se você dispensou a sugestão de idioma (armazenamento local), além da resposta de região descrita acima até você fechar a aba (armazenamento de sessão). Você pode apagá-los nas configurações do navegador.

A API para agentes (api.lumitrades.io)

A API roda no Cloudflare Workers. Para operá-la, ela mantém um registro de tráfego privado: para cada requisição, o caminho (sem a query string), o código de status, o user agent, o site de origem, o país e um hash com chave do endereço IP que muda todo dia. Endereços IP brutos não são guardados, e os registros de tráfego são apagados após 90 dias.

Os pagamentos são feitos em blockchains públicas. Para cada chamada paga, a API registra o endereço da carteira pagadora, o valor, a rede e o ID da transação, que já são públicos no ledger. As chamadas de teste gratuitas registram a carteira que assinou e um hash diário do IP, para aplicar os limites.

Se você se cadastrar no monitoramento de vendedores ou no feed de dados, a API guarda o que você enviar: o endereço da sua carteira, seus endpoints e, se você incluir, uma URL de webhook ou um e-mail para alertas. Esse e-mail é usado só para esses alertas e nunca é exibido publicamente. Relatos, respostas de vendedores e dicas enviados à API são guardados como foram enviados (relatos e dicas com um hash do endereço IP, para limitar abusos); as dicas nunca são publicadas.

Não vendemos dados

Não vendemos, alugamos nem trocamos dados pessoais. Só os compartilhamos com os prestadores de serviço citados nesta página, na medida em que precisam deles para operar o site, a newsletter e a API, ou quando a lei exige.

Suas escolhas e contato

Para cancelar a newsletter, use o link em qualquer e-mail. Para saber quais dados temos sobre você, ou pedir que sejam corrigidos ou apagados, escreva para hello@lumitrades.io. Ninguém pode alterar ou apagar pagamentos registrados em uma blockchain pública.

O site não é voltado para crianças. Se esta política mudar, esta página é atualizada e a data no topo muda.
