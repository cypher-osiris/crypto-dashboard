Dados cripto da Lumi para agentes de IA

A Lumi vende dados do mercado cripto para agentes de IA, uma chamada HTTP por vez: sinais por moeda, níveis de suporte e resistência, a lista diária de ideias de paper trading, resumos do mercado e uma lista gratuita de confiança de outros fornecedores x402. Sem conta e sem chave de API: a API responde 402 Payment Required com uma cotação, o agente paga alguns centavos e recebe os dados.

Preços por chamada em USD. Se os dados não estiverem atualizados, a API responde 503 e você não é cobrado. Grátis: /v1/coins, /openapi.json, /skill.md, /.well-known/x402.

Como pagar

  • USDC na Base (eip155:8453), liquidado pelo facilitador x402 da Coinbase. Funciona com o Coinbase AgentKit e qualquer cliente x402.
  • XRP Ledger: XRP, RLUSD ou USDC, verificado no ledger.

A cotação 402 lista cada rede, ativo, valor e endereço de recebimento aceitos; escolha um. Cabeçalhos: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE.

O fluxo 402 em duas chamadas

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i https://api.lumitrades.io/v1/signal/XRP
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl https://api.lumitrades.io/v1/signal/XRP -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

Servidor MCP

MCP remoto (streamable HTTP) para Claude, Cursor ou qualquer cliente MCP. As ferramentas gratuitas listam o catálogo, as moedas, as cotações e as pontuações de fornecedores; as pagas usam os mesmos preços x402.

{ "mcpServers": {
  "lumi": { "url": "https://api.lumitrades.io/mcp" }
} }

Opção local: npx -y lumi-trades-mcp (pacote npm lumi-trades-mcp), que paga cada chamada com os fundos do seu próprio agente e um limite de gasto por chamada; as configurações estão no README do pacote. Nome no registro: io.github.cypher-osiris/lumi-trades-mcp.

Perguntas que agentes e desenvolvedores fazem

Como meu agente de IA pode obter sinais de trading cripto?

Chame GET https://api.lumitrades.io/v1/signal/{coin} (por exemplo /v1/signal/XRP). A primeira chamada responde 402 Payment Required com uma cotação; o agente paga $0.01 com x402 e repete a chamada com o pagamento assinado para receber uma leitura de compra/venda baseada em RSI, MACD e EMA. Clientes MCP podem usar os mesmos dados em https://api.lumitrades.io/mcp. Os sinais são dados de um experimento de trading simulado de uma IA, não aconselhamento financeiro.

Existe uma API cripto de pagamento por chamada para agentes de IA?

Sim. A API da Lumi Trades vende sinais cripto, níveis de suporte e resistência, sentimento Fear & Greed da CoinMarketCap, as ideias diárias de trading simulado, um briefing diário do mercado e um Briefing diário institucional e de políticas por $0.01 a $0.25 por chamada. Não há conta, assinatura nem chave de API: cada chamada é paga separadamente com x402 e, se os dados não estiverem atualizados, a API responde 503 e nada é cobrado.

O que é x402?

x402 é um protocolo de pagamento aberto baseado no código de status HTTP 402 Payment Required, publicado primeiro pela Coinbase. Um servidor responde a uma requisição com uma cotação, o cliente a paga em uma stablecoin ou outro criptoativo e repete a requisição com o pagamento assinado, e o servidor retorna os dados com um recibo. Ele permite que software, incluindo agentes de IA, pague por requisição sem contas nem assinaturas.

Como verifico se um serviço x402 é confiável?

Antes de pagar, verifique se o endpoint retorna uma cotação 402 válida e se o endereço de pagamento e o preço batem com a documentação. Observações independentes também ajudam: a lista de confiança de fornecedores gratuita da Lumi em lumitrades.io/trust/ registra verificações automáticas de cotações e pequenas compras de teste pagas de endpoints x402, cada compra paga com link para sua transação em um explorador público do ledger, com uma pontuação de 30 dias e um nível de confiança. Comece com valores pequenos e um limite de gasto por chamada. A lista são observações, não uma avaliação de nenhuma empresa.

Como pago uma API com XRP ou RLUSD?

Com x402 no XRP Ledger: a cotação 402 lista as opções XRPL (XRP, RLUSD ou USDC) com o valor, o endereço de pagamento e os dados da fatura. Seu cliente assina um Payment XRPL exatamente nesse valor e o envia no cabeçalho PAYMENT-SIGNATURE; a API o verifica no ledger e retorna os dados com um recibo PAYMENT-RESPONSE. Para pagar em RLUSD ou USDC, a carteira pagadora precisa de uma trust line com o emissor do token e de saldo.

Posso pagar com USDC na Base?

Sim. Toda cotação também oferece USDC na Base (eip155:8453), liquidado pelo facilitador x402 da Coinbase, então o Coinbase AgentKit e outros clientes x402 funcionam sem configuração extra.

Existe um servidor MCP para dados do mercado cripto?

Sim. Adicione https://api.lumitrades.io/mcp como servidor MCP remoto (streamable HTTP) no Claude, no Cursor ou em qualquer cliente MCP. As ferramentas gratuitas listam o catálogo, as moedas, as cotações e as pontuações de fornecedores; as pagas usam os mesmos preços x402. Uma opção local é o pacote npm lumi-trades-mcp, que paga cada chamada com os fundos do próprio agente e um limite de gasto.

O que o Briefing institucional e de políticas cobre?

É um resumo diário, com fontes, do que bancos centrais, órgãos normativos e reguladores (por exemplo o BIS, o FMI e reguladores dos EUA), bancos e empresas de tokenização estão fazendo em stablecoins, CBDCs e tokenização, e de como cada item se relaciona com XRP, XLM, XDC, QNT, AXL e HBAR, separando vínculos confirmados dos indiretos. Uma chamada custa $0.25 em GET /v1/institutional.

De onde vem a leitura de Fear & Greed?

Somente do índice Fear & Greed da CoinMarketCap. GET /v1/sentiment ($0.01) o retorna junto com o funding do BTC e a amplitude do mercado.

!Dados, não aconselhamento financeiro. Os sinais e as ideias de trade vêm do experimento de paper trading de uma IA; nenhum dinheiro real é negociado.
