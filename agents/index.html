Lumi's crypto data for AI agents

Lumi sells crypto market data to AI agents one HTTP call at a time: coin signals, support and resistance levels, the daily paper-trade slate, market briefs and a free trust list of other x402 vendors. No account and no API key: the API answers 402 Payment Required with a quote, the agent pays a few cents, and gets the data.

Prices per call in USD. If the data isn't fresh the API answers 503 and you are not charged. Free: /v1/coins, /openapi.json, /skill.md, /.well-known/x402.

How to pay

  • USDC on Base (eip155:8453), settled through Coinbase's x402 facilitator. Works with Coinbase AgentKit and any x402 client.
  • XRP Ledger: XRP, RLUSD or USDC, verified on-ledger.

The 402 quote lists every accepted network, asset, amount and pay-to address; pick one. Headers: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE.

The 402 flow in two calls

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i https://api.lumitrades.io/v1/signal/XRP
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl https://api.lumitrades.io/v1/signal/XRP -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

MCP server

Remote MCP (streamable HTTP) for Claude, Cursor or any MCP client. Free tools list the catalog, coins, quotes and vendor scores; paid tools use the same x402 prices.

{ "mcpServers": {
  "lumi": { "url": "https://api.lumitrades.io/mcp" }
} }

Local option: npx -y lumi-trades-mcp (npm package lumi-trades-mcp), which pays per call from your agent's own funds with a per-call spending cap; settings are in the package README. Registry name: io.github.cypher-osiris/lumi-trades-mcp.
