Lumi for AI agents: x402 trust checks and crypto data

Lumi tests x402 sellers independently: real on-ledger test-buys, a signed receipt for each one, and coverage on the XRP Ledger, Base and Stellar. Agents can check a seller before they pay it, sellers can have their own endpoints monitored, and platforms can license the data. Lumi also sells crypto market data one call at a time. No account and no API key: the API answers 402 Payment Required with a quote, the agent pays, and gets the answer.

Check a seller before you pay

Call GET /v1/trust/check?url= with the x402 URL your agent is about to pay (optionally with the payTo and price you were quoted). It answers allow, warn or block with coded reasons, built from Lumi's index of Coinbase's x402 Bazaar, free 402-quote checks and Lumi's own test-buys. Where Lumi has bought from that seller, the paid answer carries Lumi's signed test-buy receipts, which anyone can verify for free. The vendor trust list is free. Paying Lumi, for a check or for monitoring, never changes a score.

As of Oct 23, 2026, Lumi had checked all 98 third-party hosts that list an XRPL payment option in Coinbase's x402 Bazaar, made a real XRPL mainnet purchase from 93, and 82 returned data. Every payment is an XRPL mainnet transaction.

How to pay

  • USDC on Base (eip155:8453), settled through Coinbase's x402 facilitator. Works with Coinbase AgentKit and any x402 client.
  • XRP Ledger: XRP, RLUSD or USDC, verified on-ledger.
  • USDC on Stellar (stellar:pubnet), settled through the OpenZeppelin x402 facilitator with network fees sponsored. Same USD prices as Base.

The 402 quote lists every accepted network, asset, amount and pay-to address; pick one. Headers: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE.

The 402 flow in two calls

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i https://api.lumitrades.io/v1/signal/XRP
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC, Stellar USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl https://api.lumitrades.io/v1/signal/XRP -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

Questions agents and developers ask

How can my AI agent get crypto trading signals?

Call GET https://api.lumitrades.io/v1/signal/{coin} (for example /v1/signal/XRP). The first call answers 402 Payment Required with a quote; the agent pays $0.01 with x402 and repeats the call with the signed payment to get a buy/sell read built from RSI, MACD and EMA. MCP clients can use the same data through https://api.lumitrades.io/mcp. The signals are an AI's paper-trade analysis, not financial advice.

Is there a pay-per-call crypto API for AI agents?

Yes. The Lumi Trades API sells crypto signals, support and resistance levels, CoinMarketCap Fear & Greed sentiment, the daily paper-trade slate, a daily market brief and a daily Institutional & Policy Brief for $0.003 to $0.10 per call. There is no account, subscription or API key: every call is paid on its own with x402, and if the data is not fresh the API answers 503 and nothing is charged.

What is x402?

x402 is an open payment protocol built on the HTTP status code 402 Payment Required, first published by Coinbase. A server answers a request with a price quote, the client pays it in a stablecoin or another crypto asset and repeats the request with the signed payment, and the server returns the data with a receipt. It lets software, including AI agents, pay per request without accounts or subscriptions.

How do I check if an x402 service is trustworthy?

Before paying, check that the endpoint returns a valid 402 quote and that the pay-to address and price match its documentation. Independent observations help too: Lumi's free vendor trust list at lumitrades.io/trust/ records automated quote checks and small paid test-buys of x402 endpoints, each paid buy recorded as a real ledger payment, with a 30-day score and a confidence level. Start with small amounts and a per-call spending cap. The list is observations, not a rating of any business.

How do I pay an API with XRP or RLUSD?

With x402 on the XRP Ledger: the 402 quote lists XRPL options (XRP, RLUSD or USDC) with the amount, pay-to address and invoice details. Your client signs an XRPL Payment for exactly that amount and sends it in the PAYMENT-SIGNATURE header; the API verifies it on-ledger and returns the data with a PAYMENT-RESPONSE receipt. To pay in RLUSD or USDC the paying wallet needs a trust line to the token's issuer and a balance.

Can I pay with USDC on Base?

Yes. Every quote also offers USDC on Base (eip155:8453), settled through Coinbase's x402 facilitator, so Coinbase AgentKit and other x402 clients work without extra setup.

Can I pay with USDC on Stellar?

Yes. Every quote also offers USDC on Stellar (stellar:pubnet) at the same USD prices as Base, settled through the OpenZeppelin x402 facilitator with network fees sponsored.

Is there an MCP server for crypto market data?

Yes. Add https://api.lumitrades.io/mcp as a remote MCP server (streamable HTTP) in Claude, Cursor or any MCP client. Free tools list the catalog, coins, quotes and vendor scores; paid tools use the same x402 prices. A local option is the npm package lumi-trades-mcp, which pays per call from the agent's own funds with a spending cap.

What does the Institutional & Policy Brief cover?

It is a daily, sourced summary of what central banks, standard-setters and regulators (for example the BIS, the IMF and US regulators), banks and tokenization firms are doing on stablecoins, CBDCs and tokenization, and how each item relates to XRP, XLM, XDC, QNT, AXL and HBAR, marking confirmed links apart from indirect ones. One call costs $0.10 at GET /v1/institutional.

Where does the Fear & Greed reading come from?

Only from the CoinMarketCap Fear & Greed Index. GET /v1/sentiment ($0.005) returns it together with BTC funding and market breadth.
