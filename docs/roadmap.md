# Lumi Trades: growth roadmap

A prioritized backlog for the nightly improvement job. Work **top to bottom**: pick the first unchecked item that fits in one night, ship it (test desktop + mobile, bump `?v=`, push, verify live), tick it here with the date and commit, and add follow-ups as new items. Keep the standing rules from the README: static site, no secrets, backward-compatible `data/*.json`, paper trades only, cite nothing unverified, nothing posted to X without approval.

Priority key: **P1** = biggest traffic/trust win for the effort, **P2** = solid, **P3** = nice to have / bigger bets.

## P1: next up
- [ ] **Search Console + indexing.** Have the site owner verify the property in Google Search Console and Bing Webmaster Tools (an HTML-file or meta-tag method works on Pages) and submit `sitemap.xml`. Note: crawlers only read `robots.txt` at the domain root (`cypher-osiris.github.io/robots.txt`), so the project-level file is informational; the sitemap must be submitted manually (or via a root user-site repo, which needs the owner's OK).
- [ ] **Per-coin pages** (`/coin/xrp/` etc.), static HTML generated by a script from coins.json + analysis.json + trades.json: unique title/description ("XRP price levels, signals & paper trades by an AI"), the coin's chart, levels, current idea, trade history and catalysts. Add them to the sitemap with real `<lastmod>`. The biggest long-tail search win.
- [ ] **Static, pre-rendered summary in index.html** (the slate, BTC backdrop and record written into the HTML by the update routine, then hydrated by JS) so non-JS crawlers and link unfurlers see real content.
- [ ] **Trade permalinks** (`/trades/T002/`): one page per idea with the setup, rationale, chart snapshot and outcome. Linkable from X posts, so each post drives a click to a matching page.
- [ ] **OG image per page** (per coin / per trade) reusing `make_og.py`.

## Guardrails for the nightly job
- One focused change per night, always shippable; never break `data/*.json` contracts.
- No account sign-ups, payments, outreach or X posts without the owner's explicit approval. Draft them instead.
- Every number or claim on a new page must come from the data files or a verified source.
