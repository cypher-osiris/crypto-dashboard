Pricing

The vendor trust list is free. Everything else is pay per call with x402: no account, no API key. New Base and XRPL wallets get 3 free calls in total, usable on any paid route (one trial per wallet, not per chain). Paying Lumi never changes a score or label.

Check a seller before you pay

The pay check, GET /v1/trust/check?url=, answers allow, warn or block with reasons for any x402 URL, free for 100 checks a day (per IP and per key). The full report on one vendor from the list, with tx hashes and signed receipts, is $0.02. The vendor trust list is free.
