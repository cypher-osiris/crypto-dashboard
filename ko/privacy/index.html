개인정보 처리방침

최종 업데이트: 2026년 10월 23일

Lumi Trades는 이 웹사이트(lumitrades.io)와 에이전트 API(api.lumitrades.io)를 운영합니다. 수집하는 정보는 최소한으로 줄입니다. 이 페이지는 무엇을, 누가, 왜 수집하는지 설명합니다. 개인정보를 판매하지 않으며 광고 추적기를 사용하지 않습니다.

뉴스레터

무료 일일 뉴스레터를 구독하면 입력한 이메일 주소가 구독자 목록을 보관하고 이메일을 발송하는 이메일 서비스 Kit(ConvertKit)로 전송됩니다. 구독 양식은 이메일 주소만 요청하며, 이 주소는 일일 뉴스레터 발송에만 사용됩니다.

Kit는 이메일로 구독 확인을 요청하며, 모든 뉴스레터에는 구독 해지 링크가 있어 언제든지 해지할 수 있습니다. 대부분의 이메일 서비스처럼 Kit도 이메일 열람 여부와 같은 전송 정보를 기록할 수 있습니다. Kit는 자체 개인정보 처리방침에 따라 이 데이터를 처리합니다.

분석

이 사이트는 Cloudflare Web Analytics로 방문 수를 집계합니다. 쿠키를 사용하지 않으며 다른 웹사이트에서 사용자를 추적하지 않습니다. 저희는 페이지 조회수, 유입 사이트, 국가, 브라우저 유형 같은 집계 수치만 확인합니다.

호스팅

이 웹사이트는 GitHub Pages에서 호스팅되는 정적 페이지로 이루어져 있습니다. GitHub는 서비스 운영과 보안을 위해 GitHub 개인정보 처리방침에 따라 방문자의 IP 주소와 요청 정보를 기록할 수 있습니다. 이 사이트에는 계정, 로그인, 댓글 양식이 없습니다.

제3자 콘텐츠와 링크

페이지는 Google Fonts에서 글꼴을 불러오고, 일부 페이지는 jsDelivr CDN에서 차트 라이브러리를 불러옵니다. 실시간 가격과 시장 데이터는 브라우저가 공개 API(Coinbase Exchange, Kraken, CoinGecko, OKX)에서 직접 가져옵니다. 다른 웹 요청과 마찬가지로 이 과정에서 IP 주소와 브라우저 정보가 해당 제공업체로 전송됩니다. X, YouTube, TikTok 콘텐츠는 삽입되어 있지 않으며 일반 링크일 뿐입니다.

거래소와 지갑 제조사로 연결되는 일부 링크는 제휴 또는 추천 링크입니다. 가입하시면 추가 비용 없이 저희가 수수료를 받을 수 있습니다. 표시되는 링크는 지역에 따라 다릅니다. 이를 정하기 위해 브라우저가 국가 조회 서비스(api.country.is, 대체로 ipapi.co)에 국가를 묻거나 시간대를 사용합니다. 결과는 브라우저에만 남으며 저희에게 전송되지 않습니다. 다른 사이트로 가는 링크를 따라가면 그 사이트의 개인정보 처리방침이 적용됩니다.

브라우저에 저장되는 정보

이 사이트는 쿠키를 사용하지 않습니다. 브라우저는 선택한 언어와 언어 제안을 닫았는지 여부(로컬 스토리지), 그리고 위에서 설명한 지역 결과를 탭을 닫을 때까지(세션 스토리지) 저장합니다. 브라우저 설정에서 삭제할 수 있습니다.

에이전트 API(api.lumitrades.io)

API는 Cloudflare Workers에서 실행됩니다. 운영을 위해 비공개 트래픽 로그를 보관합니다. 각 요청마다 경로(쿼리 문자열 제외), 상태 코드, 사용자 에이전트, 유입 사이트, 국가, 그리고 매일 바뀌는 키 기반 IP 주소 해시를 기록합니다. 원본 IP 주소는 저장하지 않으며, 트래픽 기록은 90일 후 삭제됩니다.

결제는 공개 블록체인에서 이루어집니다. 유료 호출마다 API는 결제자의 지갑 주소, 금액, 네트워크, 트랜잭션 ID를 기록하며, 이 정보는 원래 원장에 공개되어 있습니다. 무료 체험 호출은 한도 적용을 위해 서명한 지갑과 일일 IP 해시를 기록합니다.

판매자 모니터링이나 데이터 피드에 등록하면 API는 제출한 정보, 즉 지갑 주소, 엔드포인트, 그리고 추가한 경우 알림용 웹훅 URL이나 이메일 주소를 저장합니다. 이 이메일 주소는 해당 알림에만 사용되며 절대 공개되지 않습니다. API로 보낸 신고, 판매자 답변, 제보는 제출된 그대로 저장됩니다(신고와 제보는 악용 방지를 위해 IP 주소 해시와 함께 저장). 제보는 절대 공개되지 않습니다.

데이터를 판매하지 않습니다

저희는 개인정보를 판매, 대여, 교환하지 않습니다. 사이트, 뉴스레터, API 운영에 필요한 범위에서 이 페이지에 언급된 서비스 제공업체와만 공유하거나, 법률이 요구하는 경우에만 공유합니다.

선택권과 연락처

뉴스레터 구독을 해지하려면 이메일에 있는 링크를 이용하세요. 저희가 보관한 정보를 확인하거나 정정 또는 삭제를 요청하려면 hello@lumitrades.io로 이메일을 보내 주세요. 공개 블록체인에 기록된 결제는 누구도 변경하거나 삭제할 수 없습니다.

이 사이트는 어린이를 대상으로 하지 않습니다. 이 방침이 바뀌면 이 페이지가 업데이트되고 상단의 날짜가 바뀝니다.
