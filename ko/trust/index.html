직접 확인하기

저희 말만 믿을 필요는 없습니다. 위의 각 트랜잭션 링크는 공개 블록 익스플로러에서 Lumi의 결제를 보여 주며, 확인은 무료입니다.

  1. 판매자 선택 위 목록에서 "온체인 트랜잭션" 링크가 있는 판매자를 고르세요.
  2. 트랜잭션 해시 열기 해시를 클릭하세요. 블록 익스플로러에서 해당 판매자의 최근 테스트 구매에 대한 Lumi의 결제를 XRPL, Base 또는 Stellar 공개 원장에서 확인할 수 있습니다.
  3. 세부 정보 비교 금액, 시각, 수신자가 판매자가 게시한 x402 가격, 여기 표시된 테스트 구매 시각, 판매자의 수취(pay-to) 주소와 일치하는지 확인하세요. 가격과 수취 주소는 api.lumitrades.io/v1/trust/vendors/<seller id>의 무료 판매자 항목에 있습니다(id는 각 이름 아래 회색 텍스트입니다).
  4. 선택: 서명된 영수증 확인 각 테스트 구매에는 결제한 지갑이 서명한 영수증도 있습니다. 영수증은 유료 벤더 보고서($0.02)에 포함됩니다. 무료로 검증하려면 POST https://api.lumitrades.io/v1/trust/receipts/verify로 보내거나(?ledger=1을 붙이면 온체인 결제도 확인), 해당 주소에 안내된 단계를 따르세요.

트랜잭션 증빙은 무료입니다. 전체 기록과 서명된 영수증이 포함된 벤더 전체 보고서는 $0.02입니다. 최근 테스트 구매에 기록된 해시가 없는 판매자에게는 트랜잭션 링크가 표시되지 않습니다.
