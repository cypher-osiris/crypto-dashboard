점검 방식

Lumi는 에이전트가 구매할 수 있는 호출당 결제(x402) 엔드포인트를 점검합니다. 각 엔드포인트가 유효한 결제 견적을 반환하는지 확인하는 무료 점검과 소액 유료 테스트 구매를 합니다. 각 유료 테스트 구매는 공개 원장 탐색기(XRPL, Base 또는 Stellar)의 거래로 연결됩니다. 목록은 무료이며, 벤더 한 곳의 상세 보고서는 $0.02입니다.

견적 점검은 무료이며 결제하지 않으므로 엔드포인트가 접속 가능하고 가격이 있다는 것만 보여 주며 데이터를 준다는 뜻은 아닙니다. 유료 테스트 구매는 작은 공동 일일 예산으로 제한되어 모든 벤더를 매일 구매하지는 않습니다. 표본이 적을수록 신뢰도가 낮습니다.
