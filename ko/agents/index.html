Lumi Trades › AI 에이전트용

AI 에이전트를 위한 Lumi의 암호화폐 데이터

Lumi는 AI 에이전트에게 암호화폐 시장 데이터를 HTTP 호출 단위로 판매합니다: 코인 시그널, 지지·저항 수준, 일일 모의 투자 아이디어, 시장 브리프, 그리고 다른 x402 벤더의 무료 신뢰 목록. 계정이나 API 키가 필요 없습니다. API가 견적과 함께 402 Payment Required로 응답하면 에이전트가 몇 센트를 결제하고 데이터를 받습니다.

요금

상품엔드포인트가격
코인별 시그널(매수/매도 판단, RSI/MACD/EMA)GET /v1/signal/{coin}$0.01
지지/저항 수준 + 7일 전망GET /v1/levels/{coin}$0.01
암호화폐 심리(CoinMarketCap 공포·탐욕 지수, 펀딩비)GET /v1/sentiment$0.01
엔 캐리 트레이드 모니터(USD/JPY, 닛케이)GET /v1/macro/yen$0.015
마켓 슬레이트(오늘의 모의 투자 아이디어)GET /v1/slate$0.02
BTC + 매크로 시장 배경GET /v1/market$0.02
일일 암호화폐 시장 브리프GET /v1/brief$0.03
일일 기관·정책 브리프GET /v1/institutional$0.25
벤더 상세 보고서(전체 관찰 기록)GET /v1/trust/vendors/{id}/report$0.02
벤더 신뢰 목록GET /v1/trust/vendors무료

호출당 가격(USD)입니다. 데이터가 최신이 아니면 API가 503으로 응답하며 요금이 청구되지 않습니다. 무료: /v1/coins, /openapi.json, /skill.md, /.well-known/x402.

결제 방법

  • Base의 USDC (eip155:8453), Coinbase x402 퍼실리테이터로 정산됩니다. Coinbase AgentKit 및 모든 x402 클라이언트와 호환됩니다.
  • XRP Ledger: XRP, RLUSD 또는 USDC, 원장에서 검증됩니다.

402 견적에는 허용되는 모든 네트워크, 자산, 금액, 수취 주소가 나열되어 있으니 하나를 선택하세요. 헤더: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE.

두 번의 호출로 끝나는 402 흐름

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i https://api.lumitrades.io/v1/signal/XRP
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl https://api.lumitrades.io/v1/signal/XRP -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

MCP 서버

Claude, Cursor 또는 모든 MCP 클라이언트용 원격 MCP(streamable HTTP). 무료 도구는 카탈로그, 코인, 견적, 벤더 점수를 제공하고, 유료 도구는 동일한 x402 가격을 사용합니다.

{ "mcpServers": {
  "lumi": { "url": "https://api.lumitrades.io/mcp" }
} }

로컬 옵션: npx -y lumi-trades-mcp(npm 패키지 lumi-trades-mcp)는 호출당 지출 한도를 두고 에이전트 자체 자금으로 호출마다 결제합니다. 설정은 패키지 README에 있습니다. 레지스트리 이름: io.github.cypher-osiris/lumi-trades-mcp.

에이전트와 개발자가 자주 묻는 질문

내 AI 에이전트가 암호화폐 트레이딩 시그널을 어떻게 받을 수 있나요?

GET https://api.lumitrades.io/v1/signal/{coin}을 호출하세요(예: /v1/signal/XRP). 첫 호출은 견적과 함께 402 Payment Required로 응답합니다. 에이전트가 x402로 $0.01을 지불하고 서명된 결제와 함께 다시 호출하면 RSI, MACD, EMA 기반의 매수/매도 판단을 받습니다. MCP 클라이언트는 https://api.lumitrades.io/mcp에서 같은 데이터를 사용할 수 있습니다. 시그널은 AI의 모의 거래 실험 데이터이며 투자 조언이 아닙니다.

AI 에이전트를 위한 호출당 결제 암호화폐 API가 있나요?

네. Lumi Trades API는 암호화폐 시그널, 지지·저항 수준, CoinMarketCap Fear & Greed 심리 지표, 일일 모의 거래 아이디어, 일일 시장 브리프, 일일 기관·정책 브리프를 호출당 $0.01~$0.25에 판매합니다. 계정, 구독, API 키가 없으며 각 호출은 x402로 개별 결제됩니다. 데이터가 최신이 아니면 API가 503으로 응답하고 요금이 청구되지 않습니다.

x402란 무엇인가요?

x402는 HTTP 상태 코드 402 Payment Required를 기반으로 한 개방형 결제 프로토콜로, Coinbase가 처음 공개했습니다. 서버가 요청에 가격 견적으로 응답하면 클라이언트는 스테이블코인이나 다른 암호화폐 자산으로 이를 지불하고 서명된 결제와 함께 요청을 반복하며, 서버는 영수증과 함께 데이터를 반환합니다. AI 에이전트를 포함한 소프트웨어가 계정이나 구독 없이 요청마다 결제할 수 있게 합니다.

x402 서비스가 신뢰할 수 있는지 어떻게 확인하나요?

결제하기 전에 엔드포인트가 유효한 402 견적을 반환하는지, 수취 주소와 가격이 문서와 일치하는지 확인하세요. 독립적인 관찰도 도움이 됩니다. lumitrades.io/trust/의 무료 Lumi 벤더 신뢰 목록은 x402 엔드포인트에 대한 자동 견적 확인과 소액 유료 테스트 구매를 기록하며, 각 유료 구매는 공개 원장 탐색기의 거래로 연결되고 30일 점수와 신뢰 수준이 표시됩니다. 소액과 호출당 지출 한도로 시작하세요. 이 목록은 관찰 결과일 뿐 어떤 사업체에 대한 평가가 아닙니다.

XRP 또는 RLUSD로 API 비용을 어떻게 지불하나요?

XRP Ledger에서 x402로: 402 견적에는 금액, 수취 주소, 인보이스 정보와 함께 XRPL 옵션(XRP, RLUSD 또는 USDC)이 나열됩니다. 클라이언트가 정확히 그 금액의 XRPL Payment에 서명해 PAYMENT-SIGNATURE 헤더로 보내면, API가 원장에서 이를 검증하고 PAYMENT-RESPONSE 영수증과 함께 데이터를 반환합니다. RLUSD나 USDC로 결제하려면 결제 지갑에 토큰 발행자에 대한 trust line과 잔액이 있어야 합니다.

Base의 USDC로 결제할 수 있나요?

네. 모든 견적은 Coinbase의 x402 퍼실리테이터를 통해 정산되는 Base의 USDC(eip155:8453)도 제공하므로 Coinbase AgentKit과 다른 x402 클라이언트가 추가 설정 없이 작동합니다.

암호화폐 시장 데이터용 MCP 서버가 있나요?

네. Claude, Cursor 또는 모든 MCP 클라이언트에서 https://api.lumitrades.io/mcp를 원격 MCP 서버(streamable HTTP)로 추가하세요. 무료 도구는 카탈로그, 코인, 견적, 벤더 점수를 보여 주고, 유료 도구는 동일한 x402 가격을 사용합니다. 로컬 옵션으로는 에이전트 자체 자금으로 지출 한도 내에서 호출마다 결제하는 npm 패키지 lumi-trades-mcp가 있습니다.

기관·정책 브리프는 무엇을 다루나요?

중앙은행, 표준 제정 기관과 규제 당국(예: BIS, IMF, 미국 규제 당국), 은행 및 토큰화 기업이 스테이블코인, CBDC, 토큰화와 관련해 무엇을 하고 있는지, 그리고 각 항목이 XRP, XLM, XDC, QNT, AXL, HBAR와 어떻게 관련되는지를 출처와 함께 정리한 일일 요약이며, 확인된 연관성과 간접적인 연관성을 구분합니다. GET /v1/institutional 1회 호출에 $0.25입니다.

Fear & Greed 수치는 어디에서 오나요?

CoinMarketCap Fear & Greed 지수에서만 가져옵니다. GET /v1/sentiment($0.01)는 BTC 펀딩비 및 시장 폭과 함께 이를 반환합니다.

!데이터일 뿐 투자 조언이 아닙니다. 시그널과 트레이드 아이디어는 AI의 모의 투자 실험에서 나오며, 실제 돈으로 거래하지 않습니다.
