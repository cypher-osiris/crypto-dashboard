AI 에이전트를 위한 Lumi: x402 신뢰 확인과 암호화폐 데이터

Lumi는 x402 판매자를 독립적으로 테스트합니다: 원장에 기록되는 실제 테스트 구매, 각 구매에 대한 서명된 영수증, XRP Ledger, Base, Stellar 커버리지. 에이전트는 결제 전에 판매자를 확인할 수 있고, 판매자는 자신의 엔드포인트를 모니터링받을 수 있으며, 플랫폼은 데이터 라이선스를 받을 수 있습니다. Lumi는 암호화폐 시장 데이터도 호출 단위로 판매합니다. 계정도 API 키도 필요 없습니다: API가 견적과 함께 402 Payment Required로 응답하면 에이전트가 결제하고 답변을 받습니다.

결제하기 전에 판매자 확인

에이전트가 결제하려는 x402 URL로 GET /v1/trust/check?url=를 호출하세요(견적받은 payTo와 가격을 함께 보낼 수도 있습니다). 응답은 코드화된 이유와 함께 allow, warn 또는 block이며, Lumi의 Coinbase x402 Bazaar 색인, 무료 402 견적 확인, Lumi의 자체 테스트 구매를 바탕으로 합니다. Lumi가 해당 판매자에게서 구매한 적이 있으면 유료 응답에 Lumi의 서명된 테스트 구매 영수증이 포함되며, 누구나 무료로 검증할 수 있습니다. 판매자 신뢰 목록은 무료입니다. 확인이나 모니터링을 위해 Lumi에 비용을 내도 점수는 절대 바뀌지 않습니다.

2026년 10월 23일 기준, Lumi는 Coinbase x402 Bazaar에서 XRPL 결제 옵션을 제공하는 제3자 호스트 98곳을 모두 확인했고, 그중 93곳에서 XRPL 메인넷 실제 구매를 했으며, 82곳이 데이터를 반환했습니다. 모든 결제는 XRPL 메인넷 트랜잭션입니다.

판매자용: 모니터링과 감사

챌린지에 서명해 payTo 지갑을 관리하고 있음을 증명하고(XRPL 또는 Base. Lumi는 키나 시드를 절대 요구하지 않습니다), 엔드포인트를 무료로 등록한 뒤 x402로 플랜을 결제하세요. Lumi는 실제 결제로 엔드포인트를 테스트 구매하고, 데이터 없음, 오류, 시간 초과, 또는 payTo, 가격, 응답 스키마 변경 등 문제가 생기면 웹훅이나 이메일로 알려 드립니다.

각 테스트 구매는 $0.10으로 제한되며 플랜 요금에서 충당됩니다. 유료 플랜은 판매자의 공개 항목에 표시되고, 발견 사항은 판매자의 답변과 함께 공개 상태로 유지됩니다. “Tested by Lumi” 배지는 오직 전달 결과로만 얻을 수 있으며, 판매자의 실시간 점수가 떨어지면 자동으로 제거됩니다. 자동 갱신 없음. Lumi가 판매한 모니터링을 수행할 수 없는 경우를 제외하고 환불 없음. 그 경우 수행되지 않은 부분이 환불됩니다. 시작하는 방법

배지 받기

Lumi가 테스트한 x402 엔드포인트를 판매하시나요? 보여주세요. 무료 “Tested by Lumi” 배지는 Lumi가 저장한 귀하 서비스의 최신 유료 테스트 구매 결과와 날짜, 그리고 체인(XRPL, Base 또는 Stellar)을 표시하며, 날짜별 테스트와 반론권이 담긴 공개 결과 페이지로 연결됩니다. 가입이 필요 없고, Lumi에 비용을 지불해도 결과는 절대 바뀌지 않습니다.

예시 (실제 판매자):

delivered (녹색): 유료 응답에 데이터가 있었음 · not delivered (빨간색): 판매자가 쓸 수 있는 데이터 없이 응답함 · inconclusive (회색): Lumi가 응답을 받지 못함, 판매자에게 불리하게 계산되지 않는 Lumi 측 결과 · not yet tested: Lumi에 저장된 결과가 없음.

Lumi Market Ideas

Lumi Market Ideas모의 투자 분석이며 투자 조언이 아닙니다. Lumi는 실제 돈으로 거래하지 않습니다.

시그널, 지지·저항 레벨, 전체 코인 스캔, 모의 투자 슬레이트와 거래 기록은 Lumi Market Ideas입니다. AI의 모의 투자 분석으로, 시장 데이터처럼 호출당 판매되며 Lumi의 신뢰 검사와는 분리되어 있습니다.

결제 방법

  • Base의 USDC (eip155:8453), Coinbase x402 퍼실리테이터로 정산됩니다. Coinbase AgentKit 및 모든 x402 클라이언트와 호환됩니다.
  • XRP Ledger: XRP, RLUSD 또는 USDC, 원장에서 검증됩니다.
  • Stellar의 USDC (stellar:pubnet), OpenZeppelin x402 퍼실리테이터로 정산되며 네트워크 수수료는 후원됩니다. Base와 같은 USD 가격입니다.

402 견적에는 허용되는 모든 네트워크, 자산, 금액, 수취 주소가 나열되어 있으니 하나를 선택하세요. 헤더: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE.

두 번의 호출로 끝나는 402 흐름

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i https://api.lumitrades.io/v1/signal/XRP
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC, Stellar USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl https://api.lumitrades.io/v1/signal/XRP -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

MCP 서버

Claude, Cursor 또는 모든 MCP 클라이언트용 원격 MCP(streamable HTTP). 무료 도구는 카탈로그, 코인, 견적, 벤더 점수를 제공하고, 유료 도구는 동일한 x402 가격을 사용합니다.

{ "mcpServers": {
  "lumi": { "url": "https://api.lumitrades.io/mcp" }
} }

로컬 옵션: npx -y lumi-trades-mcp(npm 패키지 lumi-trades-mcp)는 호출당 지출 한도를 두고 에이전트 자체 자금으로 호출마다 결제합니다. 설정은 패키지 README에 있습니다. 레지스트리 이름: io.github.cypher-osiris/lumi-trades-mcp.

에이전트와 개발자가 자주 묻는 질문

내 AI 에이전트가 암호화폐 트레이딩 시그널을 어떻게 받을 수 있나요?

GET https://api.lumitrades.io/v1/signal/{coin}을 호출하세요(예: /v1/signal/XRP). 첫 호출은 견적과 함께 402 Payment Required로 응답합니다. 에이전트가 x402로 $0.01을 지불하고 서명된 결제와 함께 다시 호출하면 RSI, MACD, EMA 기반의 매수/매도 판단을 받습니다. MCP 클라이언트는 https://api.lumitrades.io/mcp에서 같은 데이터를 사용할 수 있습니다. 시그널은 AI의 모의 거래 분석이며 투자 조언이 아닙니다.

AI 에이전트를 위한 호출당 결제 암호화폐 API가 있나요?

네. Lumi Trades API는 암호화폐 시그널, 지지·저항 수준, CoinMarketCap Fear & Greed 심리 지표, 일일 모의 거래 아이디어, 일일 시장 브리프, 일일 기관·정책 브리프를 호출당 $0.003~$0.10에 판매합니다. 계정, 구독, API 키가 없으며 각 호출은 x402로 개별 결제됩니다. 데이터가 최신이 아니면 API가 503으로 응답하고 요금이 청구되지 않습니다.

x402란 무엇인가요?

x402는 HTTP 상태 코드 402 Payment Required를 기반으로 한 개방형 결제 프로토콜로, Coinbase가 처음 공개했습니다. 서버가 요청에 가격 견적으로 응답하면 클라이언트는 스테이블코인이나 다른 암호화폐 자산으로 이를 지불하고 서명된 결제와 함께 요청을 반복하며, 서버는 영수증과 함께 데이터를 반환합니다. AI 에이전트를 포함한 소프트웨어가 계정이나 구독 없이 요청마다 결제할 수 있게 합니다.

x402 서비스가 신뢰할 수 있는지 어떻게 확인하나요?

결제하기 전에 엔드포인트가 유효한 402 견적을 반환하는지, 수취 주소와 가격이 문서와 일치하는지 확인하세요. 독립적인 관찰도 도움이 됩니다: lumitrades.io/trust/에 있는 Lumi의 무료 벤더 신뢰 목록은 x402 엔드포인트의 자동 견적 점검과 소액 유료 테스트 구매를 기록하며, 각 유료 구매는 실제 원장 결제로 기록되고 30일 점수와 신뢰 수준이 함께 제공됩니다. 소액과 호출당 지출 한도로 시작하세요. 이 목록은 관찰일 뿐 어떤 사업체에 대한 평가도 아닙니다.

XRP 또는 RLUSD로 API 비용을 어떻게 지불하나요?

XRP Ledger에서 x402로: 402 견적에는 금액, 수취 주소, 인보이스 정보와 함께 XRPL 옵션(XRP, RLUSD 또는 USDC)이 나열됩니다. 클라이언트가 정확히 그 금액의 XRPL Payment에 서명해 PAYMENT-SIGNATURE 헤더로 보내면, API가 원장에서 이를 검증하고 PAYMENT-RESPONSE 영수증과 함께 데이터를 반환합니다. RLUSD나 USDC로 결제하려면 결제 지갑에 토큰 발행자에 대한 trust line과 잔액이 있어야 합니다.

Base의 USDC로 결제할 수 있나요?

네. 모든 견적은 Coinbase의 x402 퍼실리테이터를 통해 정산되는 Base의 USDC(eip155:8453)도 제공하므로 Coinbase AgentKit과 다른 x402 클라이언트가 추가 설정 없이 작동합니다.

Stellar의 USDC로 결제할 수 있나요?

네. 모든 견적은 Base와 같은 USD 가격으로 Stellar의 USDC(stellar:pubnet)도 제공하며, 네트워크 수수료가 대납되는 OpenZeppelin x402 퍼실리테이터를 통해 정산됩니다.

암호화폐 시장 데이터용 MCP 서버가 있나요?

네. Claude, Cursor 또는 모든 MCP 클라이언트에서 https://api.lumitrades.io/mcp를 원격 MCP 서버(streamable HTTP)로 추가하세요. 무료 도구는 카탈로그, 코인, 견적, 벤더 점수를 보여 주고, 유료 도구는 동일한 x402 가격을 사용합니다. 로컬 옵션으로는 에이전트 자체 자금으로 지출 한도 내에서 호출마다 결제하는 npm 패키지 lumi-trades-mcp가 있습니다.

기관·정책 브리프는 무엇을 다루나요?

중앙은행, 표준 제정 기관과 규제 당국(예: BIS, IMF, 미국 규제 당국), 은행 및 토큰화 기업이 스테이블코인, CBDC, 토큰화와 관련해 무엇을 하고 있는지, 그리고 각 항목이 XRP, XLM, XDC, QNT, AXL, HBAR와 어떻게 관련되는지를 출처와 함께 정리한 일일 요약이며, 확인된 연관성과 간접적인 연관성을 구분합니다. GET /v1/institutional 1회 호출에 $0.10입니다.

Fear & Greed 수치는 어디에서 오나요?

CoinMarketCap Fear & Greed 지수에서만 가져옵니다. GET /v1/sentiment($0.005)는 BTC 펀딩비 및 시장 폭과 함께 이를 반환합니다.
