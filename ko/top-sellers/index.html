판매자가 이 목록에 오르는 방법

최근 유료 테스트 구매에서 데이터를 제공했고, 최근 3번의 유료 테스트 구매 중 최소 2번 데이터를 제공했으며, 마지막 테스트 구매가 45일 이내인 판매자가 목록에 오릅니다.

결론이 나지 않은 테스트 구매(응답을 받지 못한 경우, 저희 측 문제)는 집계하지 않습니다.

대부분의 판매자는 지금까지 테스트 구매를 한 번만 받았습니다. 다음 테스트 구매 후에 여기에 오를 수 있습니다.

각 카테고리에서는 데이터 제공에 성공한 테스트 구매가 많은 판매자가 먼저, 그다음 가장 최근에 테스트한 판매자 순입니다.

카테고리는 Coinbase x402 Bazaar 카탈로그에 있는 각 판매자의 공개 설명이나 저희 자체 판매자 목록에서 가져옵니다.

Lumi에 비용을 지불해도 목록 포함 여부나 순서는 절대 바뀌지 않습니다. 이해 상충 정책을 확인하세요.
