How the checks work

Lumi checks pay-per-call (x402) endpoints that agents can buy from: a free check that each endpoint returns a valid payment quote, plus small paid test-buys. Each paid test-buy links to its transaction on a public ledger explorer (XRPL, Base or Stellar). The list is free; a detailed report on one vendor costs $0.02.

Quote checks are free and unpaid, so they show an endpoint is reachable and priced, not that it delivers. Paid test-buys are capped at a small shared daily budget, so not every vendor is bought every day; fewer samples means lower confidence.

Right to reply

If you run one of these endpoints and think an observation is wrong or missing context, you can add a reply that is shown with your entry. Email hello@lumitrades.io, or post a signed reply to POST https://api.lumitrades.io/v1/trust/replies, signed with the key of a pay-to address listed for your entry (details in the methodology). We can also re-run a check or remove an endpoint from the list on request.
