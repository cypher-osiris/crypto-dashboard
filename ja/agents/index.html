AIエージェント向けLumi：支払う前にx402販売者をチェック

Lumiはx402販売者を独立してテストします。台帳上の実際のテスト購入、購入ごとの署名付きレシート、そしてXRP Ledger、Base、Stellarへの対応です。エージェントは支払う前に販売者をチェックでき、販売者は自分のエンドポイントを監視してもらえ、プラットフォームはデータをライセンス利用できます。有料の呼び出しはすべて同じ仕組みです。アカウントもAPIキーも不要です。APIは見積もり付きの402 Payment Requiredを返し、エージェントが支払うと回答を受け取れます。

支払う前に販売者を確認

エージェントが支払おうとしているx402のURLでGET /v1/trust/check?url=を呼び出します（提示されたpayToと価格を添えることもできます）。回答はコード化された理由付きのallow、warn、blockで、LumiによるCoinbase x402 Bazaarの索引、無料の402見積もりチェック、Lumi自身のテスト購入にもとづきます。Lumiがその販売者から購入したことがある場合、有料の回答にはLumiの署名付きテスト購入レシートが含まれ、誰でも無料で検証できます。販売者の信頼リストは無料です。チェックや監視のためにLumiへ支払っても、スコアが変わることはありません。

2026年10月23日時点で、LumiはCoinbaseのx402 BazaarでXRPL決済を掲載している第三者ホスト98件すべてをチェックし、93件から購入しました。82件がデータを納品し、2件は納品せず、9件はLumi側のエラーにより判定できませんでした（販売者の不利には数えていません）。すべての支払いはXRPLメインネットの取引です。

ベンダーの完全レポート（$0.02）

ベンダー1社の完全レポートはウェブページではなく、エージェント向けの有料x402 API呼び出しです：GET https://api.lumitrades.io/v1/trust/vendors/{id}/report は$0.02の見積もり付きで 402 Payment Required を返し、x402クライアントが支払って呼び出しを繰り返します。レポートには、ベンダーの全観察履歴、エクスプローラーへのリンク付きのすべてのtxハッシュ、署名付きテスト購入レシートが含まれます。

販売者の確認には不要です：信頼リスト、各販売者の最新txハッシュ、レシートの検証は無料です。x402の支払いは呼び出しごとで、取り消しできません。 2 回の呼び出しで完結する 402 フロー · ベンダー信頼リスト（無料）

料金と無料トライアル

有料ルートは3件、1回あたり$0.01〜$0.02です。無料トライアル：新しいBaseとXRPLのウォレットには合計3回の無料呼び出しがあり、どの有料ルートでも使えます（X-Lumi-Trial: 1を送信し、0.01 USDC以上を保有するBaseウォレット、または有効化済みのXRP Ledgerアカウントでサインインしてください。チェーンごとではなくウォレットごとに1回、資金は移動しません）。

1 回あたりの価格（USD）。データが最新でない場合、API は 503 を返し、料金はかかりません。無料: /openapi.json、/skill.md、/.well-known/x402。

支払い方法

  • Base 上の USDC（eip155:8453）。Coinbase の x402 ファシリテーターで決済されます。Coinbase AgentKit やあらゆる x402 クライアントで使えます。
  • XRP Ledger: XRP、RLUSD または USDC。レジャー上で検証されます。
  • Stellar上のUSDC（stellar:pubnet）。OpenZeppelinのx402ファシリテーターで決済され、ネットワーク手数料はスポンサー負担です。Baseと同じUSD価格です。

402 見積もりには受け付けるすべてのネットワーク、資産、金額、受取アドレスが記載されているので、1 つを選びます。ヘッダー: PAYMENT-REQUIRED、PAYMENT-SIGNATURE、PAYMENT-RESPONSE。

支払い先アドレス：Lumiの支払い先アドレス（payTo）は、必ずライブの402支払いレスポンスまたは/.well-known/x402から取得してください。取引履歴や過去の送金から取らないでください。

2 回の呼び出しで完結する 402 フロー

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i "https://api.lumitrades.io/v1/trust/check?url=https://api.example.com/v1/data"
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC, Stellar USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl "https://api.lumitrades.io/v1/trust/check?url=https://api.example.com/v1/data" -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

MCP サーバー

Claude、Cursor、その他のMCPクライアント向けのリモートMCP（streamable HTTP）。無料ツールでカタログ、価格、販売者スコアを取得でき、有料ツールは同じx402価格です。

{ "mcpServers": {
  "lumi": { "url": "https://api.lumitrades.io/mcp" }
} }

ローカル版：npx -y lumi-trades-mcp（npmパッケージlumi-trades-mcp）。エージェント自身の資金から呼び出しごとに支払い、1回あたりの支出上限があります。設定はパッケージのREADMEにあります。

エージェントと開発者からのよくある質問

AIエージェントは支払う前にx402販売者をどう確認できますか？

エージェントが支払おうとしているx402 URLを指定して GET https://api.lumitrades.io/v1/trust/check?url= を呼び出します。最初の呼び出しは見積もり付きで402 Payment Requiredを返します。エージェントがx402で$0.02を支払い、署名付きの支払いで呼び出しを繰り返すと、コード化された理由とともにallow、warn、blockのいずれかが返されます。MCPクライアントは https://api.lumitrades.io/mcp で同じチェックを利用できます。回答は日付付きの証拠であり、保証ではありません。

x402 とは？

x402 は HTTP ステータスコード 402 Payment Required に基づくオープンな決済プロトコルで、Coinbase が最初に公開しました。サーバーがリクエストに価格見積もりで応答し、クライアントがステーブルコインや他の暗号資産で支払って署名済みの支払いを付けてリクエストを繰り返すと、サーバーは領収書とともにデータを返します。AI エージェントを含むソフトウェアが、アカウントやサブスクリプションなしでリクエストごとに支払えるようにします。

x402 サービスが信頼できるか確認するには？

支払う前に、エンドポイントが有効な402見積もりを返すか、支払先アドレスと価格がドキュメントと一致するかを確認しましょう。独立した観測も役立ちます：lumitrades.io/trust/ にあるLumiの無料ベンダー信頼リストは、x402エンドポイントの自動見積もりチェックと少額の有料テスト購入を記録し、各有料購入は実際のレジャー上の支払いとして記録され、30日間のスコアと信頼度が付きます。少額と1回あたりの支出上限から始めてください。このリストは観測結果であり、いかなる事業者の評価でもありません。

XRP や RLUSD で API の料金を支払うには？

XRP Ledger 上の x402 では、402 見積もりに金額、支払先アドレス、請求書情報とともに XRPL のオプション（XRP、RLUSD、USDC）が記載されます。クライアントがちょうどその金額の XRPL Payment に署名して PAYMENT-SIGNATURE ヘッダーで送ると、API が台帳上で検証し、PAYMENT-RESPONSE の領収書とともにデータを返します。RLUSD や USDC で支払うには、支払い側のウォレットにトークン発行者へのトラストラインと残高が必要です。

Base の USDC で支払えますか？

はい。すべての見積もりで、Coinbase の x402 ファシリテーター経由で決済される Base の USDC（eip155:8453）も選べるため、Coinbase AgentKit などの x402 クライアントは追加設定なしで動作します。

Stellar の USDC で支払えますか？

はい。すべての見積もりで、Base と同じ USD 価格の Stellar の USDC（stellar:pubnet）も選べます。決済は OpenZeppelin の x402 ファシリテーター経由で、ネットワーク手数料はスポンサー負担です。

x402の信頼チェック向けMCPサーバーはありますか？

はい。Claude、Cursor、その他のMCPクライアントで、https://api.lumitrades.io/mcp をリモートMCPサーバー（streamable HTTP）として追加してください。無料ツールでカタログ、価格、販売者スコアを取得でき、有料ツールは同じx402価格です。ローカル版としてnpmパッケージlumi-trades-mcpがあり、エージェント自身の資金から支出上限付きで呼び出しごとに支払います。
