AI エージェント向け Lumi の暗号資産データ

Lumi は AI エージェントに暗号資産市場データを HTTP 呼び出し 1 回単位で販売しています: コインごとのシグナル、サポート・レジスタンス水準、毎日のペーパートレードアイデア、市場ブリーフ、他の x402 ベンダーの無料信頼リスト。アカウントも API キーも不要で、API が見積もり付きで 402 Payment Required を返し、エージェントが数セント支払うとデータを受け取れます。

料金

商品エンドポイント価格

1 回あたりの価格（USD）。データが最新でない場合、API は 503 を返し、料金はかかりません。無料: /v1/coins、/openapi.json、/skill.md、/.well-known/x402。

支払い方法

  • Base 上の USDC（eip155:8453）。Coinbase の x402 ファシリテーターで決済されます。Coinbase AgentKit やあらゆる x402 クライアントで使えます。
  • XRP Ledger: XRP、RLUSD または USDC。レジャー上で検証されます。

402 見積もりには受け付けるすべてのネットワーク、資産、金額、受取アドレスが記載されているので、1 つを選びます。ヘッダー: PAYMENT-REQUIRED、PAYMENT-SIGNATURE、PAYMENT-RESPONSE。

2 回の呼び出しで完結する 402 フロー

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i https://api.lumitrades.io/v1/signal/XRP
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl https://api.lumitrades.io/v1/signal/XRP -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

MCP サーバー

Claude、Cursor などあらゆる MCP クライアント向けのリモート MCP（streamable HTTP）。無料ツールでカタログ、コイン、見積もり、ベンダースコアを取得でき、有料ツールは同じ x402 価格です。

{ "mcpServers": {
  "lumi": { "url": "https://api.lumitrades.io/mcp" }
} }

ローカルの選択肢: npx -y lumi-trades-mcp（npm パッケージ lumi-trades-mcp）は、呼び出しごとの支出上限付きでエージェント自身の資金から支払います。設定はパッケージの README にあります。レジストリ名: io.github.cypher-osiris/lumi-trades-mcp。
