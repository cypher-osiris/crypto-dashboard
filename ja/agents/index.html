AIエージェント向けLumi：x402の信頼チェックと暗号資産データ

Lumiはx402の販売者を独立してテストします：台帳に記録される実際のテスト購入、その一件ごとの署名付きレシート、XRP Ledger、Base、Stellarのカバレッジ。エージェントは支払う前に販売者を確認でき、販売者は自分のエンドポイントを監視してもらえ、プラットフォームはデータのライセンスを受けられます。Lumiは暗号資産のマーケットデータも1コール単位で販売しています。アカウントもAPIキーも不要：APIが見積もり付きの402 Payment Requiredを返し、エージェントが支払うと回答が届きます。

支払う前に販売者を確認

エージェントが支払おうとしているx402のURLでGET /v1/trust/check?url=を呼び出します（提示されたpayToと価格を添えることもできます）。回答はコード化された理由付きのallow、warn、blockで、LumiによるCoinbase x402 Bazaarの索引、無料の402見積もりチェック、Lumi自身のテスト購入にもとづきます。Lumiがその販売者から購入したことがある場合、有料の回答にはLumiの署名付きテスト購入レシートが含まれ、誰でも無料で検証できます。販売者の信頼リストは無料です。チェックや監視のためにLumiへ支払っても、スコアが変わることはありません。

2026年10月23日時点で、LumiはCoinbaseのx402 BazaarでXRPLの支払いオプションを掲載している第三者ホスト98件をすべて確認し、そのうち93件からXRPLメインネットで実際に購入し、82件がデータを返しました。すべての支払いはXRPL台帳で確認できます。

販売者向け：監視と監査

バッジを入手

Lumiがテストしたx402エンドポイントを販売していますか？それを示しましょう。無料の「Tested by Lumi」バッジは、Lumiが保存しているあなたのサービスの最新の有料テスト購入の判定と日付、そしてチェーン（XRPL、BaseまたはStellar）を表示し、日付入りのテスト結果と反論の権利を載せた公開結果ページにリンクします。登録は不要で、Lumiに支払っても結果が変わることはありません。

例（実在の販売者）：

delivered（緑）：有料レスポンスにデータが含まれていた · not delivered（赤）：販売者は使えるデータなしで応答した · inconclusive（グレー）：Lumiが応答を確認できなかった。Lumi側の結果で、販売者に不利には数えません · not yet tested：Lumiに保存された結果がありません。

キーを確認

支払い方法

  • Base 上の USDC（eip155:8453）。Coinbase の x402 ファシリテーターで決済されます。Coinbase AgentKit やあらゆる x402 クライアントで使えます。
  • XRP Ledger: XRP、RLUSD または USDC。レジャー上で検証されます。
  • Stellar上のUSDC（stellar:pubnet）。OpenZeppelinのx402ファシリテーターで決済され、ネットワーク手数料はスポンサー負担です。Baseと同じUSD価格です。

402 見積もりには受け付けるすべてのネットワーク、資産、金額、受取アドレスが記載されているので、1 つを選びます。ヘッダー: PAYMENT-REQUIRED、PAYMENT-SIGNATURE、PAYMENT-RESPONSE。

2 回の呼び出しで完結する 402 フロー

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i https://api.lumitrades.io/v1/signal/XRP
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC, Stellar USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl https://api.lumitrades.io/v1/signal/XRP -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

MCP サーバー

Claude、Cursor などあらゆる MCP クライアント向けのリモート MCP（streamable HTTP）。無料ツールでカタログ、コイン、見積もり、ベンダースコアを取得でき、有料ツールは同じ x402 価格です。

{ "mcpServers": {
  "lumi": { "url": "https://api.lumitrades.io/mcp" }
} }

ローカルの選択肢: npx -y lumi-trades-mcp（npm パッケージ lumi-trades-mcp）は、呼び出しごとの支出上限付きでエージェント自身の資金から支払います。設定はパッケージの README にあります。レジストリ名: io.github.cypher-osiris/lumi-trades-mcp。

エージェントと開発者からのよくある質問

AI エージェントで暗号資産のトレーディングシグナルを取得するには？

GET https://api.lumitrades.io/v1/signal/{coin} を呼び出します（例：/v1/signal/XRP）。最初の呼び出しは見積もり付きの 402 Payment Required を返します。エージェントが x402 で $0.01 を支払い、署名済みの支払いを付けて再度呼び出すと、RSI、MACD、EMA に基づく売買判断が得られます。MCP クライアントは https://api.lumitrades.io/mcp から同じデータを利用できます。シグナルは AI のペーパートレード実験のデータであり、投資助言ではありません。

AI エージェント向けの従量課金型暗号資産 API はありますか？

はい。Lumi Trades API は暗号資産シグナル、サポート・レジスタンス水準、CoinMarketCap の Fear & Greed センチメント、日次のペーパートレードのアイデア、デイリー市場ブリーフ、デイリー機関投資家・政策ブリーフを 1 回 $0.003〜$0.10 で販売しています。アカウント、サブスクリプション、API キーは不要で、各呼び出しは x402 で個別に支払います。データが最新でない場合、API は 503 を返し、料金は発生しません。

x402 とは？

x402 は HTTP ステータスコード 402 Payment Required に基づくオープンな決済プロトコルで、Coinbase が最初に公開しました。サーバーがリクエストに価格見積もりで応答し、クライアントがステーブルコインや他の暗号資産で支払って署名済みの支払いを付けてリクエストを繰り返すと、サーバーは領収書とともにデータを返します。AI エージェントを含むソフトウェアが、アカウントやサブスクリプションなしでリクエストごとに支払えるようにします。

x402 サービスが信頼できるか確認するには？

支払う前に、エンドポイントが有効な 402 見積もりを返すこと、支払先アドレスと価格がドキュメントと一致することを確認してください。独立した観測も役立ちます。lumitrades.io/trust/ にある Lumi の無料ベンダー信頼リストは、x402 エンドポイントの見積もり自動チェックと少額の有料テスト購入を記録しており、各有料購入は公開台帳エクスプローラー上の取引にリンクされ、30 日間スコアと信頼度が付いています。少額と呼び出しごとの支出上限から始めてください。このリストは観測結果であり、いかなる事業者の格付けでもありません。

XRP や RLUSD で API の料金を支払うには？

XRP Ledger 上の x402 では、402 見積もりに金額、支払先アドレス、請求書情報とともに XRPL のオプション（XRP、RLUSD、USDC）が記載されます。クライアントがちょうどその金額の XRPL Payment に署名して PAYMENT-SIGNATURE ヘッダーで送ると、API が台帳上で検証し、PAYMENT-RESPONSE の領収書とともにデータを返します。RLUSD や USDC で支払うには、支払い側のウォレットにトークン発行者へのトラストラインと残高が必要です。

Base の USDC で支払えますか？

はい。すべての見積もりで、Coinbase の x402 ファシリテーター経由で決済される Base の USDC（eip155:8453）も選べるため、Coinbase AgentKit などの x402 クライアントは追加設定なしで動作します。

Stellar の USDC で支払えますか？

はい。すべての見積もりで、Base と同じ USD 価格の Stellar の USDC（stellar:pubnet）も選べます。決済は OpenZeppelin の x402 ファシリテーター経由で、ネットワーク手数料はスポンサー負担です。

暗号資産の市場データ向け MCP サーバーはありますか？

はい。Claude、Cursor、その他の MCP クライアントで https://api.lumitrades.io/mcp をリモート MCP サーバー（streamable HTTP）として追加してください。無料ツールではカタログ、コイン、見積もり、ベンダースコアを確認でき、有料ツールは同じ x402 価格を使います。ローカルの選択肢として、エージェント自身の資金から支出上限付きで呼び出しごとに支払う npm パッケージ lumi-trades-mcp があります。

機関投資家・政策ブリーフは何を扱っていますか？

中央銀行、基準設定機関や規制当局（例：BIS、IMF、米国の規制当局）、銀行、トークン化企業がステーブルコイン、CBDC、トークン化について何をしているか、そして各項目が XRP、XLM、XDC、QNT、AXL、HBAR とどう関係するかを出典付きでまとめた日次サマリーで、確認済みの関連と間接的な関連を区別しています。GET /v1/institutional の 1 回の呼び出しは $0.10 です。

Fear & Greed の値はどこから取得していますか？

CoinMarketCap の Fear & Greed 指数のみです。GET /v1/sentiment（$0.005）は、BTC のファンディングと市場の広がりと合わせてこれを返します。
