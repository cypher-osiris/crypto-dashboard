Política de privacidad

Última actualización: 25 oct 2026

Lumi Trades gestiona este sitio web (lumitrades.io) y la API para agentes (api.lumitrades.io). Recopilamos lo mínimo posible. Esta página explica qué se recopila, quién lo hace y por qué. No vendemos datos personales ni usamos rastreadores publicitarios.

Boletín

Si te suscribiste al boletín, la dirección de correo que introdujiste se envía a Kit (ConvertKit), el servicio de correo que guarda la lista de suscriptores y envía los correos. Solo se usa para enviar el boletín.

Kit te pide confirmar la suscripción por email, y cada boletín incluye un enlace para darte de baja: puedes cancelar cuando quieras. Como la mayoría de los servicios de email, Kit puede registrar datos de entrega, como si se abrió un correo. Kit trata estos datos según su propia política de privacidad.

Analítica

El sitio cuenta las visitas con Cloudflare Web Analytics. No usa cookies ni te sigue por otros sitios web. Solo vemos cifras agregadas, como páginas vistas, sitios de referencia, países y tipos de navegador.

Alojamiento

El sitio web es un conjunto de páginas estáticas alojadas en GitHub Pages. GitHub puede registrar las direcciones IP de los visitantes y detalles de las solicitudes para operar y proteger su servicio, según la declaración de privacidad de GitHub. El sitio no tiene cuentas, inicios de sesión ni formularios de comentarios.

Contenido y enlaces de terceros

Las páginas cargan fuentes de Google Fonts. Las páginas de confianza de proveedores obtienen los últimos resultados de pruebas de la propia API de Lumi (api.lumitrades.io); como cualquier solicitud web, esto envía tu dirección IP y los datos de tu navegador a ese servicio. No hay nada incrustado de X, YouTube ni TikTok; son enlaces simples. Al seguir un enlace a otro sitio, se aplica la política de privacidad de ese sitio.

Guardado en tu navegador

Este sitio no usa cookies. Tu navegador guarda tu elección de idioma y si descartaste la sugerencia de idioma (almacenamiento local). Puedes borrarlos en la configuración de tu navegador.

La API para agentes (api.lumitrades.io)

La API funciona en Cloudflare Workers. Para operarla, guarda un registro de tráfico privado: por cada solicitud, la ruta (sin la cadena de consulta), el código de estado, el user agent, el sitio de referencia, el país y un hash con clave de la dirección IP que cambia cada día. No se guardan direcciones IP en claro, y los registros de tráfico se borran a los 90 días.

Los pagos se hacen en blockchains públicas. Por cada llamada pagada, la API registra la dirección de wallet del pagador, el importe, la red y el ID de la transacción, que de todos modos son públicos en el ledger. Las llamadas de prueba gratuitas registran la wallet que firmó y un hash diario de la IP, para aplicar los límites.

Si te registras en la monitorización de vendedores o en el feed de datos, la API guarda lo que envías: tu dirección de wallet, tus endpoints y, si los añades, una URL de webhook o un email para alertas. Ese email solo se usa para esas alertas y nunca se muestra públicamente. Los reportes, las respuestas de vendedores y los avisos enviados a la API se guardan tal como se envían (los reportes y avisos, con un hash de la dirección IP para limitar abusos); los avisos nunca se publican.

Lumi Check

Por ahora, esta sección solo está disponible en inglés.

Lumi Check is a free check an agent can run before it pays an x402 seller. It answers allow, warn or block, shown as one label (Delivered in recent checks, Check first, Recent checks failed or Not enough data), with reasons, the seller's score and a link to the live report. The answer is signed by Lumi so the agent can verify it.

Checks. When you run a check, the kit sends only the seller URL's origin and path (any query string is removed before it leaves your machine), or the seller's pay-to address, plus the price if you give one. We don't store who checked what. A checked seller that shows a warning signal may be queued for a test-buy. Short-lived counters (for rate limits) are kept in memory and are not stored.

What the kit shares. Tier 1, off until you say yes: nothing is sent before you agree. Right after your first check, the kit asks once: “Share your results to help improve Lumi's public trust list? [Y/n]”. Your answer is saved only on your computer, and the question is not shown again. Where the kit cannot ask (no terminal, CI, the MCP server or code), sharing stays off. If you say yes, after a paid call the kit sends one anonymous delivery outcome: the seller's host name or Lumi endpoint ID, whether the data was delivered (yes or no) and optionally a coarse status class (for example 2xx, 5xx or timeout). Each report carries a new random token that is used once to drop duplicates and cannot be linked to you or to your other reports. It never includes your wallet, the amount, the transaction hash, the query string, the response, or any stable ID. Tier 1 reports are counted only; they never change a seller's score. To change your answer at any time, run lumi-scan telemetry on or lumi-scan telemetry off, set LUMI_CHECK_TELEMETRY=on or off, or set "telemetry": true or false in the kit's config file.

Tier 2, off by default: sharing full signed receipts. Nothing is sent unless you turn it on (lumi-scan sharing on or LUMI_SHARE_RECEIPTS=1). Each shared receipt includes the payment's transaction ID. A transaction ID is public on its blockchain: anyone who has it can look it up and link it to the wallet that paid and the amount. If you take part, the API stores what you register and submit: a label you choose, your contributor public key, the wallet addresses you pay from, any domains you tell us you own, and the wallet that first funded each registered wallet (read from the public ledger, used to tell independent contributors apart). Your contributor private key and wallet secrets stay on your machine and are never sent to us.

For each receipt you share we store the receipt and the test data in it: the seller endpoint (origin and path only) and the seller's pay-to address, the payment's network and transaction ID, HTTP status, outcome, timing, response size, a hash and a schema fingerprint of the response (field names and types, not the content), data freshness, facilitator and settlement time. Receipts contain no amount, price or wallet field, and we refuse receipts that do. Response bodies are never uploaded. We check each receipt against the public ledger before it counts: that the wallet that signed it paid the seller. We do not store the amount. We keep the paying wallet's address (read from the ledger) with the submission only to run the anti-abuse checks below; it is never published or shown by any public page or API.

Rewards. Contributors get a public, pseudonymous contributor badge, optionally with a count of verified contributions (at most one per seller per day). That is the only reward: there are no credits, money, perks, rankings or rate-limit changes, and sharing never changes how any score is computed. The 'Tested by Lumi' badge is earned only and can never be bought; it is removed automatically when the seller's score drops below the threshold. Paying Lumi never changes a score, tier, ranking or 'Tested by Lumi' result. The paid 'Monitored by Lumi' badge is separate and labelled as paid.

We use this data to score sellers, to prevent self-testing and abuse (for example, limits per key, per endpoint and per funding source), and to show your badge. Findings can appear in Lumi's seller observations and badges in combined form; your key id and wallets are not shown with them. Demand statistics are off by default; if you opt in, your purchases are counted only in aggregate, at domain level, with at least two contributors per row and no key ids or wallets.

How long we keep it. Raw data is kept for 90 days and then deleted: that covers tier 1 outcome counters, contributor submissions (including the stored receipt copy). A raw tier 1 day is deleted only after it has been summarised. The summaries are kept long-term: one row per seller per day, holding the number of delivered and failed purchases and coarse status classes. They contain no wallet address, amount, transaction ID, URL query, payload or anything that identifies you. Your contributor account (key ID, public key and registered wallets) is kept while it is active, meaning you submitted a verified receipt in the last 12 months, and is not deleted at 90 days. You can see your own submissions and your badge at any time through the contributor API. You do not get, and we do not share, the raw pooled database. To ask about your contributor data, email hello@lumitrades.io.

Deleting your contributor account. You can delete it yourself at any time with lumi-scan account delete (it asks you to type your key ID first), or email hello@lumitrades.io and we delete it the same way. Deletion is immediate and cannot be undone. Deleted: your key (it can never be used again), label, public key, registered wallets and the funding wallet recorded for each, any domains you told us you own, your demand opt-in, your last-activity date, your badge, and every receipt you shared, including the stored copy, unless we have already cited it in a published, dated test result. Kept, with no link to you: receipts already cited in a published, dated test result, with your wallet signature, paying-wallet address, kit details and key ID removed (the transaction ID, seller and delivery result stay because the published result cites them, and they are still deleted after 90 days like other raw data); the anonymous per-seller daily summaries and tier 1 counters, which never had a link to you; and a record that the deleted key ID existed, so it cannot be reused. Transactions on a public blockchain cannot be deleted by anyone, including us.

Seller payment analysis

Por ahora, esta sección solo está disponible en inglés.

Seller payment analysis. To describe x402 sellers and to spot self-payment, Lumi reads public blockchain payments to sellers' listed pay-to addresses. We group payer wallets by funding source and publish only ranges and flags for sellers, never payer wallets or dollar amounts. Raw wallet-level data is kept up to 90 days and then deleted; aggregates are kept. We don't try to identify payers. If you think a payer wallet is yours and want us to stop processing it, email hello@lumitrades.io and we will exclude it (you can object at any time). Legal basis (EU/UK): legitimate interests in reporting on and preventing manipulation of a public payment market.

No vendemos datos

No vendemos, alquilamos ni intercambiamos datos personales. Solo los compartimos con los proveedores de servicios citados en esta página, en la medida en que los necesitan para operar el sitio, el boletín y la API, o cuando la ley lo exige.

Tus opciones y contacto

Para darte de baja del boletín, usa el enlace de cualquier email. Para saber qué datos tenemos sobre ti, o pedir que se corrijan o se borren, escribe a hello@lumitrades.io. Nadie puede modificar ni borrar los pagos registrados en una blockchain pública.

El sitio no está dirigido a menores. Si esta política cambia, se actualiza esta página y cambia la fecha de arriba.
