Lumi para agentes de IA: comprobaciones de confianza x402 y datos cripto

Lumi prueba vendedores x402 de forma independiente: compras de prueba reales registradas en el ledger, un recibo firmado de cada una y cobertura en varias cadenas con foco en el XRP Ledger. Los agentes pueden comprobar un vendedor antes de pagarle, los vendedores pueden hacer monitorear sus propios endpoints y las plataformas pueden licenciar los datos. Lumi también vende datos del mercado cripto llamada a llamada. Sin cuenta ni clave de API: la API responde 402 Payment Required con una cotización, el agente paga y recibe la respuesta.

Comprueba un vendedor antes de pagar

Llama a GET /v1/trust/check?url= con la URL x402 que tu agente está por pagar (opcionalmente con el payTo y el precio que te cotizaron). Responde allow, warn o block con motivos codificados, a partir del índice de Lumi del x402 Bazaar de Coinbase, comprobaciones gratuitas de cotizaciones 402 y las compras de prueba de Lumi. Si Lumi ya compró a ese vendedor, la respuesta de pago incluye los recibos firmados de esas compras de prueba, que cualquiera puede verificar gratis. La lista de confianza de proveedores es gratis. Pagar a Lumi, por una comprobación o por el monitoreo, nunca cambia una puntuación.

Al 23 oct 2026, Lumi había revisado todos los 98 hosts de terceros que ofrecen una opción de pago en XRPL en el x402 Bazaar de Coinbase, hizo una compra real en la red principal de XRPL a 93 de ellos, y 82 devolvieron datos. Cada pago se puede comprobar en el ledger de XRPL.

Cómo pagar

  • USDC en Base (eip155:8453), liquidado mediante el facilitador x402 de Coinbase. Funciona con Coinbase AgentKit y cualquier cliente x402.
  • XRP Ledger: XRP, RLUSD o USDC, verificado en el ledger.
  • USDC en Stellar (stellar:pubnet), liquidado mediante el facilitador x402 de OpenZeppelin, con las comisiones de red patrocinadas. Mismos precios en USD que en Base.

La cotización 402 indica cada red, activo, importe y dirección de cobro aceptados; elige uno. Cabeceras: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE.

El flujo 402 en dos llamadas

# 1. ask: no key, no account. The API answers 402 with a quote
curl -i https://api.lumitrades.io/v1/signal/XRP
#    HTTP/2 402
#    PAYMENT-REQUIRED: <base64 JSON: price, networks (Base USDC, XRPL XRP/RLUSD/USDC), payTo>

# 2. pay with any x402 client, then repeat the call with the signed payment
curl https://api.lumitrades.io/v1/signal/XRP -H "PAYMENT-SIGNATURE: <payment payload>"
#    HTTP/2 200 + the data, PAYMENT-RESPONSE: <settlement receipt>

Servidor MCP

MCP remoto (streamable HTTP) para Claude, Cursor o cualquier cliente MCP. Las herramientas gratuitas muestran el catálogo, las monedas, las cotizaciones y las puntuaciones de proveedores; las de pago usan los mismos precios x402.

{ "mcpServers": {
  "lumi": { "url": "https://api.lumitrades.io/mcp" }
} }

Opción local: npx -y lumi-trades-mcp (paquete npm lumi-trades-mcp), que paga cada llamada con los fondos de tu propio agente y un límite de gasto por llamada; la configuración está en el README del paquete. Nombre en el registro: io.github.cypher-osiris/lumi-trades-mcp.

Preguntas frecuentes de agentes y desarrolladores

¿Cómo puede mi agente de IA obtener señales de trading cripto?

Llama a GET https://api.lumitrades.io/v1/signal/{coin} (por ejemplo /v1/signal/XRP). La primera llamada responde 402 Payment Required con una cotización; el agente paga $0.01 con x402 y repite la llamada con el pago firmado para obtener una lectura de compra/venta basada en RSI, MACD y EMA. Los clientes MCP pueden usar los mismos datos en https://api.lumitrades.io/mcp. Las señales son datos de un experimento de trading simulado de una IA, no asesoramiento financiero.

¿Existe una API cripto de pago por llamada para agentes de IA?

Sí. La API de Lumi Trades vende señales cripto, niveles de soporte y resistencia, sentimiento Fear & Greed de CoinMarketCap, las ideas diarias de trading simulado, un informe diario del mercado y un Informe Institucional y de Políticas diario por $0.003 a $0.25 por llamada. No hay cuenta, suscripción ni clave de API: cada llamada se paga por separado con x402 y, si los datos no están actualizados, la API responde 503 y no se cobra nada.

¿Qué es x402?

x402 es un protocolo de pago abierto basado en el código de estado HTTP 402 Payment Required, publicado primero por Coinbase. Un servidor responde a una solicitud con una cotización, el cliente la paga en una stablecoin u otro criptoactivo y repite la solicitud con el pago firmado, y el servidor devuelve los datos con un recibo. Permite que el software, incluidos los agentes de IA, pague por solicitud sin cuentas ni suscripciones.

¿Cómo compruebo si un servicio x402 es fiable?

Antes de pagar, comprueba que el endpoint devuelve una cotización 402 válida y que la dirección de pago y el precio coinciden con su documentación. También ayudan las observaciones independientes: la lista de confianza de proveedores gratuita de Lumi en lumitrades.io/trust/ registra comprobaciones automáticas de cotizaciones y pequeñas compras de prueba pagadas de endpoints x402, cada compra pagada enlazada a su transacción en un explorador público del ledger, con una puntuación de 30 días y un nivel de confianza. Empieza con importes pequeños y un límite de gasto por llamada. La lista son observaciones, no una calificación de ningún negocio.

¿Cómo pago una API con XRP o RLUSD?

Con x402 en el XRP Ledger: la cotización 402 enumera las opciones XRPL (XRP, RLUSD o USDC) con el importe, la dirección de pago y los datos de la factura. Tu cliente firma un Payment de XRPL por exactamente ese importe y lo envía en el encabezado PAYMENT-SIGNATURE; la API lo verifica en el ledger y devuelve los datos con un recibo PAYMENT-RESPONSE. Para pagar en RLUSD o USDC, la cartera que paga necesita una trust line con el emisor del token y saldo.

¿Puedo pagar con USDC en Base?

Sí. Cada cotización también ofrece USDC en Base (eip155:8453), liquidado mediante el facilitador x402 de Coinbase, así que Coinbase AgentKit y otros clientes x402 funcionan sin configuración adicional.

¿Hay un servidor MCP para datos del mercado cripto?

Sí. Añade https://api.lumitrades.io/mcp como servidor MCP remoto (streamable HTTP) en Claude, Cursor o cualquier cliente MCP. Las herramientas gratuitas muestran el catálogo, las monedas, las cotizaciones y las puntuaciones de proveedores; las de pago usan los mismos precios x402. Una opción local es el paquete npm lumi-trades-mcp, que paga cada llamada con los fondos del propio agente y un límite de gasto.

¿Qué cubre el Informe Institucional y de Políticas?

Es un resumen diario, con fuentes, de lo que hacen bancos centrales, organismos de normalización y reguladores (por ejemplo el BIS, el FMI y los reguladores de EE. UU.), bancos y empresas de tokenización en stablecoins, CBDC y tokenización, y de cómo se relaciona cada noticia con XRP, XLM, XDC, QNT, AXL y HBAR, separando los vínculos confirmados de los indirectos. Una llamada cuesta $0.25 en GET /v1/institutional.

¿De dónde sale la lectura de Fear & Greed?

Solo del índice Fear & Greed de CoinMarketCap. GET /v1/sentiment ($0.005) lo devuelve junto con el funding de BTC y la amplitud del mercado.
